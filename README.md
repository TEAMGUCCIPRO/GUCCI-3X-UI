## امکانات و قابلیت‌های کلیدی GUCCI 3X-UI

- **پشتیبانی کامل و جامع از تمامی پروتکل‌ها:** VLESS, VMess, Trojan, Shadowsocks, WireGuard, Hysteria2, HTTP, SOCKS, TUN
- **ترنسپورت‌ها و روش‌های مدرن ضد فیلترینگ:** TCP (Raw), mKCP, WebSocket, gRPC, HTTPUpgrade, XHTTP با TLS / REALITY
- **سیستم لندینگ و ریدایرکت اختصاصی برند GUCCI:** همراه با رابط کاربری لوکس، انیمیشن‌های پویا و طراحی واکنش‌گرا
- **مدیریت پیشرفته کلاینت‌ها:** سهمیه حجم مصرفی، انقضای زمانی، لیمیت تعداد IP متصل همزمان و مسدودسازی خودکار با Fail2ban
- **ربات هوشمند تلگرام:** مدیریت کامل پنل از راه دور، صدور کانفیگ، ارسال وضعیت منابع سرور، و تهیه پشتیبان خودکار
- **سرور سابسکریپشن اختصاصی:** اتصال هوشمند با لینک‌های تجمیعی برای Clash, V2rayN, Sing-Box, Streisand, Shadowrocket
- **رابط کاربری مدرن، زیبا و چندزبانه:** با پشتیبانی کامل از زبان‌های فارسی، انگلیسی و تم‌های تاریک و روشن
